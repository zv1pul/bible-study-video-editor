Optional. Drop a .ttf or .otf font in this folder and the overlays will use it
instead of the system font (files with "Bold" in the name are used for headings).

Free fonts that look good on video:
  Inter          https://fonts.google.com/specimen/Inter
  Source Sans 3  https://fonts.google.com/specimen/Source+Sans+3
  Montserrat     https://fonts.google.com/specimen/Montserrat

You can also point at a specific file instead:
  OVERLAY_FONT=/path/to/Regular.ttf
  OVERLAY_FONT_BOLD=/path/to/Bold.ttf
